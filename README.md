# 阿威专属海钓

个人使用的微信小程序：以鲅鱼圈望海寨 / 广航一带为默认地区，可通过下拉菜单切换国内多个沿海地区，并可自建地区、自定义经纬度与范围，按地区维护外海 / 内湾 / 养殖圈信息。把钓点档案、鱼种季节、本人钓记知识库和出海工具整合在一个小程序里，供本人及少数钓友查阅。

## 功能

- **地区选择**：首页、钓点、鱼情、钓记、记一笔、工具箱、往年今日顶部均有地区下拉菜单，默认「广航 · 鲅鱼圈望海寨」，可选营口、大连、丹东、秦皇岛、天津、烟台、威海、青岛、连云港、舟山、厦门、汕头、湛江、三亚及其他地区。切换后页面文案、钓点、鱼种、钓记、潮汐定位提示、往年今日查询范围全部同步更新；选择结果本机保存，下次打开沿用
- **自定义定位**：地区栏「定位设置」或首页入口进入。可给任意地区（含内置地区）设置中心经纬度、范围半径、定位精度、潮汐定位点与位置备注；还可基于任一内置地区模板新建自定义地区，支持改名、切换与删除。删除自定义地区前会自动备份全部钓记，并把该地区记录转移到其资料模板地区；也可手动备份或从备份恢复。经纬度与半径会校验范围，不调用地图或定位接口
- **海域类型信息**：按地区录入、修改、展示并本机保存「外海」「内湾」「养殖圈」的名称、说明与注意事项。钓点页顶部有只读速览与编辑入口，编辑页可恢复默认
- **首页**：船讯网、Windy 官网快捷入口（复制网址到浏览器打开），今日提示与钓点速览
- **钓点**：望海寨龟石滩、广航防波堤·珍珠湾、沈鼓集团周边北海大坝外侧三处档案，附卫星地貌判读
- **鱼情**：海鲶鱼、鲅鱼、梭鱼、黑鲪、海鲈 5 种鱼的 12 个月窗口期色块表，海况截图数值读法
- **工具**：农历潮汐经验窗口速查（明确非精确潮时）、按当前地区坐标生成的 Windy / 高德 / 国家海洋预报台查询链接（复制到浏览器打开，小程序不联网）、装备清单（勾选状态本机保存）、安全须知、资料来源（首页入口进入）
- **钓记**：本人 2026 年 5 次广航海钓亲身记录（日期、农历、潮汐窗口、渔获、钓法、关键事件）与规律总结
- **记一笔**：出钓记录表单，下拉选钓点、钓点结构、潮汐、天气、风力风向、水况、钓法、鱼种、海域类型，可填渔获与备注、附最多 6 张图片，存本机；已有记录可点「编辑」修改（不会重复新增），或用「转移地区」改挂到其他地区
- **往年今日渔获**：输入或选择日期（如 `08-17`、`8月17日`、`2026-08-17`、`今天`），查询历史上同一天的渔获总量、按年份汇总（含横向柱状条）、当日记录明细，并与当前日期对比。支持无数据、无效日期、未来日期等边界提示
- **海钓乐趣词语**：35 条钓友黑话与海钓术语，分渔获心情 / 作钓动作 / 鱼情水况 / 装备线组 / 钓友文化 5 类，含拼音与通俗解释，支持分类切换与全文搜索
- **数据管理**：一键导出全部本机数据（钓记、地区、定位参数、海域信息、装备勾选）为 JSON 备份文件，或从备份合并/覆盖导入；换手机可迁移。删除记录会同步清理其图片文件，图片上传自动压到长边 ≤1280px / 质量 0.7

## 技术说明

- 原生微信小程序（WXML / WXSS / JS），无后端、无登录、无网络请求
- 所有内容打包在工程内；装备勾选状态与「记一笔」记录用 `wx.setStorageSync` 存在手机本机，不上传
- 「记一笔」图片用 `wx.chooseMedia` 选图后经 `copyFileSync` 存到 `USER_DATA_PATH` 永久目录，避免临时文件失效
- 「往年今日」查询为纯本地计算（`utils/anniversary.js`，不依赖平台 API，网页版复用同一套逻辑）：日期解析、数量提取、同月日匹配、按年份汇总与今日对比均在本机完成，响应即时
- 地区集中管理：`utils/regions.js` 是地区注册表与取数入口，`utils/region-mixin.js` 提供各页共用的切换逻辑，`templates/region-bar.wxml` 是共用下拉条。当前地区写入 `fishing_region_v1`
- 广航 bundle 直接复用原有 `data.js`、`fishing-log.js`、`form-options.js`，5 次钓记与三处钓点档案完全保留；其他地区使用通用模板，钓点为地形类型占位、鱼种窗口期为空，不编造本地数据
- 「记一笔」新记录写入 `region` 与 `zone` 字段；列表与「往年今日」按当前地区过滤。**旧记录没有 `region` 字段时按广航处理**，切换地区只改变查看范围，不会删除任何已有记录
- 钓记统一通过 `utils/record-store.js` 读写，存 `fishing_records_v1`；支持按 id 更新、单条转移地区、批量改挂、备份（`fishing_records_backup_v1`）与恢复，避免各页面各自操作存储造成数据不一致
- 定位参数存 `fishing_region_params_v1`（按地区 id 索引），自定义地区存 `fishing_custom_regions_v1`，海域类型信息存 `fishing_zones_v1`（按地区 id 索引）；四者全部为本机存储，不上传
- 定位参数变化会更新地区的 `rev` 标识，共用 mixin 在页面 `onShow` 时据此刷新，参数改动无需重启即可在其他页面生效
- tabBar 保持微信上限内的 5 项；工具、往年今日、乐趣词语、自定义定位、海域类型从首页入口以 `navigateTo` 进入
- 图片素材：海况 App 截图与卫星地貌截图，均来自用户提供的公开来源，仅供个人参考

## 如何扩展地区

只需改一处：`utils/regions.js` 顶部的 `REGION_META` 数组，按同样格式加一项：

```js
{ id: 'beihai', name: '北海 · 北部湾', short: '北海', tideLocation: '北海' }
```

加完即可在下拉菜单中选择，页面会自动使用通用模板（明确标注非本地实测），无需改任何页面代码。

若要给该地区配专属资料，在同一文件的 `BUNDLE_OVERRIDES` 里按地区 id 加一项，只填想覆盖的字段，其余自动沿用通用模板：

```js
var BUNDLE_OVERRIDES = {
  beihai: {
    spots: [ /* 该地区的钓点档案 */ ],
    logs: [ /* 该地区的亲身钓记，结构同 utils/fishing-log.js */ ],
    dataNote: '',
    showSatellite: false
  }
};
```

可覆盖字段与 `makeGuanghangBundle()` 一致：`spots`、`fishes`、`gear`、`safety`、`sources`、`seaGuide`、`tideAdvice`、`logs`、`insights`、`boundaries`、`formOptions`、`tips`、`tipWarn`、`anniversarySpot`、`logTitle`、`logSub`、`logCardText`、`logNote`、`anniversaryNote`、`dataNote`、`showSatellite`。

> 「海钓乐趣词语」是全地区通用的术语速查，不随地区切换。
> 不想改代码时，可直接在「自定义定位」页新建地区，无需动 `REGION_META`。

## 自定义定位与海域类型

**定位参数**：在地区栏点「定位设置」，选择要调整的地区后填写中心纬度、中心经度、范围半径、定位精度、潮汐定位点与备注。纬度限 -90~90、经度限 -180~180、半径限 0~500 公里，经纬度需同时填写。保存后：
- 该地区的潮汐工具提示改用你填的「潮汐定位点」（留空则恢复默认）
- 其他页面看到的地区概况与参数同步更新
- 自定义地区可基于任一内置地区的资料模板，创建后自动切换过去；内置地区不可删除

**海域类型**：在「海域类型」页编辑当前地区的外海 / 内湾 / 养殖圈。三类条目固定，名称、说明、注意事项都可改，按地区分别保存，可一键恢复默认。保存后：
- 「钓点」页顶部按当前地区展示三类信息速览
- 「记一笔」的「海域类型」下拉使用修改后的名称，并写入每条记录
- 「往年今日」的当日明细会显示记录所属海域类型

> 这些参数与描述完全由你自行维护，小程序不提供地图选点、坐标反查或实时海况；坐标与半径只作个人记录与识别用途。

**钓记安全**：在「自定义定位」页可「立即备份全部钓记」，备份只存本机。删除自定义地区时自动备份并把记录转移到基础地区；「从备份恢复」会用备份覆盖当前全部钓记，操作前会有二次确认。删除单条记录不可恢复，重要记录请先备份。

## 如何用微信开发者工具打开

1. 下载并安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 选择「导入项目」，项目目录选中本仓库根目录
3. AppID 填写自己的小程序 AppID（工程内为游客模式 `touristappid`，仅可预览）
4. 点击「编译」即可预览

> 本项目为个人自用，未针对通用发布做适配。正式发布需在微信公众平台完成账号、类目与备案等流程。

## 数据来源与边界（重要）

| 内容 | 来源 | 说明 |
|---|---|---|
| 钓点地貌 | 营口市自然资源局海域使用论证公示、腾讯新闻赶海攻略、公开 POI | 仅文字描述与公开坐标，未标注敏感设施 |
| 农历日期 | 香港天文台《2026 年公历与农历日期对照表》 | 已核实 |
| 潮汐窗口 | 按农历经验划分（初一至初四、十六至十八为大潮） | **经验判断，非精确潮时**，精确值需用潮汐 App 定位鲅鱼圈查询 |
| 鱼种窗口期 | 钓友经验分享 | 非官方统计 |
| 钓记 5 次记录 | 本人 2026 年亲身经历 | 记不清的潮汐/天气标注"未记录"，未编造 |
| 往年今日渔获 | 上述钓记 + 本机「记一笔」记录 | 仅按"同月同日"跨年匹配；"爆箱"等无具体数量的标注为未知、**不计入总量、不估算**；空军记为 0；同日均值仅对可计数记录求平均 |
| 海钓乐趣词语 | 钓友通用说法与本人理解 | 供查阅娱乐，各地含义可能略有差异 |
| 海况截图 | 用户提供的天气 App 截图 | 历史数据、模型预报，**不代表当前海况** |
| 非广航地区资料 | 通用模板 | 钓点为地形类型占位、鱼种窗口期为空、无钓记与来源链接；页面已明确标注，**不是当地实测数据**，不可当作当地鱼情依据 |
| 自定义定位参数 | 用户自行填写 | 经纬度、半径、精度均由本机录入；小程序不调用地图/定位接口，**不保证坐标准确**，仅供个人识别 |
| 外海 / 内湾 / 养殖圈 | 通用描述 + 用户自行修改 | 默认文字为经验性说明（广航有少量结合公开资料的补充），**不是测绘或管控依据**；养殖圈按管控区域处理，是否可进入以现场告示为准 |

规律基于 5 次样本归纳，样本量小，属经验假设，不是定论。目前钓记仅 2026 年一年数据，"按年份汇总"多数日期只有一行，逐年积累后对比更有意义。赤潮等异常水况请立即停钓，安全第一。

```
fishing-miniapp/
├── app.js / app.json / app.wxss      全局配置与样式
├── pages/                            十个页面
│   ├── index / spots / fish          首页 / 钓点 / 鱼情（tabBar）
│   ├── log / record                  钓记 / 记一笔（tabBar）
│   ├── tools                         工具箱（首页入口）
│   ├── anniversary                   往年今日渔获（首页入口）
│   ├── words                         海钓乐趣词语（首页入口）
│   ├── region                        自定义定位与地区管理（首页入口 / 地区栏）
│   ├── zone                          外海 / 内湾 / 养殖圈 信息（首页入口 / 钓点页）
│   └── data                          数据管理：导出 / 导入备份（首页入口）
├── utils/
│   ├── data.js                       钓点、鱼种、装备等结构化数据
│   ├── fishing-log.js                钓记知识库数据
│   ├── form-options.js               「记一笔」下拉选项
│   ├── anniversary.js                往年今日查询逻辑（纯计算，两端复用）
│   ├── fishing-words.js              海钓乐趣词语数据
│   ├── regions.js                    地区注册表、自定义地区、定位参数、按地区取数
│   ├── region-mixin.js               各页面共用的地区切换逻辑
│   ├── record-store.js               钓记读写、编辑更新、地区转移、备份与恢复、删图清理
│   ├── data-backup.js                全量数据导出 / 导入（合并去重 / 覆盖）
│   └── zone-info.js                  外海 / 内湾 / 养殖圈 按地区读写
├── templates/
│   └── region-bar.wxml               共用地区下拉条
├── images/                           实景参考图片
├── project.config.json               项目配置（游客 appid）
├── LICENSE                           MIT 许可证
└── sitemap.json
```
网页版助手 `fishing-assistant.html` 位于仓库上一级工作目录，**不在本仓库内**，二者数据格式独立（网页版记录用 `wfz_fishing_records_v1`，不能与小程序备份文件直接互导）。网页版已同步地区下拉、自定义定位参数、海域类型编辑、钓记编辑与地区转移、数据导出导入；广航专属资料（钓点档案、鱼情、亲身钓记、实景参考）只在广航地区展示，其他地区明确标注为通用模板。两边的 5 次广航钓记、16 个地区选项、内湾术语保持一致。
